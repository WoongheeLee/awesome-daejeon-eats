Issue로 기여하기 (간편한 방법)

  1. 저장소의 'Issues' 탭으로 이동합니다.
  2. 'New issue' 버튼을 클릭합니다.
  3. 제목에 맛집/카페 이름을, 내용에 주소와 간단한 설명을 작성합니다.
  4. 'Submit new issue' 버튼을 클릭하여 제출합니다.

Pull Request로 기여하기

  1. 이 저장소를 포크(Fork)합니다.
  2. 새로운 브랜치를 만듭니다.
  3. 변경사항을 커밋합니다.
  4. 포크한 저장소에 푸시합니다.
  5. 이 저장소로 Pull Request를 생성합니다.
